## 📊 Project Overview

This project implements a comprehensive data mining pipeline for epileptic seizure detection using EEG datasets. We analyze how preprocessing order, regularization methods (L1/L2/Elastic Net), and imbalance handling techniques affect logistic regression performance.

### Key Findings
- **Preprocessing order** affects performance by 8-12%
- **Elastic Net** generalizes best across datasets with correlated features  
- **SMOTE** improves recall but reduces precision (tradeoff)
- **Class weighting** is most stable across different regularization methods
